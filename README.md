# Project RF
A protoype game inspired by Road Rash (1999) built in Game Maker

Note: When compiling, it is recommended to use YYC compilier

## Download from itch.io!
https://mackwafang.itch.io/project-rf

## Controls
### Menu
Up/Down arrow - Select option

Left/Right arrow - Change option

Space - Start

### Gameplay
C - Accelerate

X - Boost (yellow bar)

Z - Brake

Left / Right arrow - Turn left/right

F11 - Change UI modes
